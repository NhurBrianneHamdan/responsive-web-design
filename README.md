# [Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design-v9/)

This repository consists of activities and projects I have made using HTML and CSS based on freeCodeCamp's [Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design-v9/) course. In this Responsive Web Design Certification, you'll learn the languages that developers use to build webpages: HTML (Hypertext Markup Language) for content, and CSS (Cascading Style Sheets) for design.
